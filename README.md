# Stylish Song — HTML/CSS Collaboration

Course project implementing a radial background, styled heading, gradient lyric cards, and a special fifth-paragraph style.

## Files
- `index.html` — semantic HTML page, with original placeholder text to be replaced with course-provided song lyrics.
- `styles.css` — required CSS styles.
- `submission.txt` — submission template; complete partner names and verify URLs before submitting.

## Collaboration workflow
Exactly two partners are required. Invite your actual partner to the repository. Each person should make meaningful changes on their own feature branch, push, open a pull request, and have the other partner review it before merging. Do not fabricate commits or collaboration evidence.

## Local preview
Open `index.html` in a browser.
